Voice Family Agent

A voice-first AI surface where one phone call gives anyone access to AI execution — regardless of literacy, age, or tech comfort. A 6-year-old calling parents, an 80-year-old booking medicine, a farmer outsourcing crops to a verified vendor, a CEO scheduling tasks — all through one number, all using the same agent. Skeleton system is built (Android + Bolna voice surface + per-user LLM bindings + planner that decomposes free-text intent). Currently wiring up the planner-to-execution path.

Architecture Phase

Clerk

A multi-party, multi-agent orchestration layer. Born from a real failure observed while building Voice Family Agent — when AI is asked to execute multi-step tasks across multiple agents, it breaks somewhere in the chain. Clerk's job is to hold the chain together: shared memory across agents, group-level consent, persistent state, steering, and interrupts. Currently in architecture and requirements phase; build starts after specs are locked.
